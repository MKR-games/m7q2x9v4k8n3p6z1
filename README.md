# 똑... 똑... 똑... — 이야기의 배경 영상 전용 페이지

QR 접속용 독립형 영상 플레이어입니다. 기존 게임 설명서 내용은 포함하지 않습니다.

## 구성
- `index.html` — 화면/UI/재생 기능 전체
- `assets/story-background.mp4` — 이야기의 배경 영상
- `PretendardVariable.woff2` — 사용 폰트
- `Pretendard_LICENSE.txt` — 폰트 라이선스

## 기능
- 수동 재생 시작 (자동재생 없음)
- 재생 / 일시정지 / 다시 재생
- 재생 위치 이동
- 현재 시간 / 전체 길이 표시
- 로딩 표시
- 음소거 / 음량 조절
- 0.5~2배속 재생
- 전체화면 및 모바일 전체화면 대응
- iOS/Android `playsinline` 대응
- 세이프 에어리어 대응
- 모바일 세로 9:16 중심 레이아웃
